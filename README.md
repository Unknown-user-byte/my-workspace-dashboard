# 개인 업무 대시보드

현재 파일은 `index.html` 하나로 실행되는 정적 웹 대시보드 시제품입니다.

## GitHub Pages 게시
1. GitHub에서 새 저장소를 만듭니다. 저장소 이름 예: `my-workspace-dashboard`.
2. 저장소 공개 범위는 GitHub Pages 사용 조건과 보안 요구를 확인해 선택합니다. 일반적인 GitHub Pages 사이트는 저장소가 private이어도 사이트 자체가 공개될 수 있으므로, 페이지 주소가 비공개라고 가정하면 안 됩니다.
3. 이 폴더의 `index.html`과 `README.md`를 저장소 최상위(root)에 올립니다.
4. 저장소의 **Settings → Pages**로 이동합니다.
5. **Deploy from a branch**를 선택하고 `main` 브랜치의 `/ (root)`를 지정한 뒤 저장합니다.
6. 배포가 완료되면 Pages 화면에 표시되는 사이트 주소로 접속합니다.

## 현재 기능과 제한
- 3열 대시보드, 카드형 시계, 수동 일정, 업무 목록, 습관 체크, 메모, 오늘의 초점, 바로가기
- 카드 드래그 이동 및 3단계 크기 변경 시도 기능
- 사용자가 입력한 일정·메모·업무 등은 브라우저의 `localStorage`에 저장됩니다. 다른 PC/브라우저와 자동 동기화되지 않습니다.
- 날씨는 실제 날씨 API에 연결되어 있지 않습니다.
- 캘린더는 로컬 입력 일정만 표시하며 Google Calendar와 연결되어 있지 않습니다.
- 뉴스는 설정한 RSS 주소 1개를 외부 프록시를 통해 가져오는 방식입니다. 프록시 가용성은 보장되지 않습니다.
- Google OAuth 연동, 자동 다중 RSS 수집, 위젯별 자유로운 폭·높이 조절은 아직 구현되지 않았습니다.

## 보안 주의
- 사이트 주소는 공개될 수 있습니다. 공개 사이트에 비밀번호, 토큰, OAuth client secret, 내부 문서 또는 민감한 업무 정보를 넣지 마세요.
- 현재 버전은 브라우저 로컬 저장을 사용하지만, RSS 주소와 요청은 외부 RSS 프록시 서비스에 전달될 수 있습니다. 사내 전용 피드나 비공개 피드는 등록하지 않는 것을 권장합니다.
- Google Calendar 연동은 별도 OAuth 설정과 최소 권한 범위가 필요합니다. 비공개 일정을 공개 캘린더로 바꿀 필요는 없습니다.
